# Slim R6P

![Slim rear isometric](images/iso_opposite.png)

The slim baffle combines V1L lower/mid pieces with the V1 top. Its main
acoustic field occupies z=6.8..18.3, so it is 11.5 mm deep and shares the
same front plane. The bottom structural strip remains full-depth to z=0.

Print all four `slim_{1..4}_of_4_*` pieces and choose the matching thin V1
shoulders or thin V1 wings. Do not substitute the 18.3 mm Stock attachments.
Use the V1L split grommet for its 283-degree UM exit.

This family is experimental and still requires real-driver, Faston,
cable-routing, stiffness, and assembled-mode checks.
