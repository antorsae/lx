## Normalization Rationale

- Juan and Andres absolute SPL levels are not assumed to be matched, so the primary validation compares normalized polar shape: SPL(theta)-SPL(0) at each frequency.
- The single scalar gain and delay align the validation comparison only; they are not source-fit parameters and cannot change normalized polar or directivity errors.
- The gate summary now also exports complex relative RMS after that same one gain/delay alignment. This exposes the optional complex-pressure residual without adding any source, rear, angle, or band-specific correction.
- On-axis SPL error after scalar gain is reported separately from the normalized-polar acceptance result.
- Baffle-transfer metrics use the same dataset-level reference alignment as validation before subtracting the nude equivalent source at Andres mic height. This is not a rear/source level correction and does not change normalized polar or directivity errors.
